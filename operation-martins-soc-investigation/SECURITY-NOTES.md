# Security Notes

This repository documents a simulated cybersecurity exercise conducted in an isolated virtual testbed.

## Public-release controls

- No real passwords, API keys, tokens, private keys, or production credentials should be published.
- Credential-like lab values visible in screenshots are not reproduced in repository text.
- Review screenshots before public release for accidental secrets or personal information.
- Treat all IP addresses and hostnames in this project as laboratory artifacts.
- Do not apply the documented activity to systems without explicit authorization.

## Portfolio positioning

The strongest professional focus of this project is the **defensive lifecycle**: telemetry collection → detection → investigation → IoC identification → containment → eradication → recovery → hardening.
