# Security Notes

This repository documents a simulated cybersecurity exercise conducted in an isolated virtual testbed.

## Safe publication rules

- Do not publish real passwords, API keys, tokens, private keys, or production credentials.
- Do not connect the lab techniques to systems without explicit authorization.
- Treat all IP addresses and hostnames in this project as laboratory artifacts.
- Keep the original evidence screenshots as portfolio evidence, but redact any future screenshots that contain real secrets.
- The repository is primarily intended to demonstrate defensive SOC investigation, SIEM analysis, threat hunting, and incident response.

## Portfolio positioning

The strongest professional focus of this project is the **defensive lifecycle**: telemetry collection → detection → investigation → IoC identification → containment → eradication → recovery.
