# Project Summary

## Project

**Operation Martins — Simulated Breach Investigation & SOC Defense Architecture**

## Scenario

An isolated virtual testbed was used to model an enterprise domain environment and investigate suspicious authentication activity.

## Deliverables demonstrated

- Baseline network architecture
- Traffic inspection
- Log ingestion and SIEM pipeline
- Detection analytics
- Threat hunting
- Incident timeline
- IoC identification
- Incident response

## Primary SOC competencies demonstrated

- Security monitoring
- Windows event analysis
- SIEM investigation
- Network traffic analysis
- Threat hunting
- Evidence correlation
- Incident containment
- Eradication and recovery
- Security hardening

## Portfolio takeaway

The project demonstrates a complete defensive investigation lifecycle: establish a baseline, collect telemetry, detect anomalies, correlate evidence, contain the source, validate the environment, recover affected resources, and implement controls intended to reduce recurrence.
